# 拼布

无需注册、打开就能动手的中文布艺线索板。可把布片、花瓣、针脚、相框、自己的照片和文字自由摆放，完成旅行手账、纪念板或贺卡，并导出高清 PNG 与可继续编辑的项目文件。

## 本地运行

```bash
pnpm install
pnpm generate:assets
pnpm dev
```

浏览器打开终端显示的本地地址。生产构建：

```bash
pnpm build
pnpm preview
```

静态文件输出到 `dist/`，可部署到任意静态托管服务。

## 已实现

- 默认原创示例板、空白板与横/竖/方三种尺寸
- 布片、零件、相框、灵感系列四类素材；颜色和纹样筛选
- 点按或桌面拖放添加，物件移动、旋转、缩放、复制、删除、层级调整
- 可拆开的预组合布花；拆开保持视觉位置并支持撤销恢复
- 双端可调的独立针脚线
- JPG/PNG/WebP 文件选择与拖放；照片独立放置或落入相框
- 相框内照片平移、缩放、换框保留裁切
- 中英文字、数字、换行、字号与颜色
- 视口平移、缩放、回到全景；键盘撤销/重做、删除和方向键微移
- IndexedDB 自动保存，多作品互不覆盖，刷新恢复
- 2× 高清 PNG 导出；包含用户照片的 `.pinbu.json` 项目导入导出
- 损坏图片、HEIC、无效项目和保存/导出失败的中文错误提示
- 响应式桌面与移动端素材抽屉

## 本地数据与隐私

这是纯前端应用。用户照片、排版和裁切数据保存在当前浏览器 IndexedDB；照片不会上传。项目文件会把照片以 data URL 包含在 JSON 中，适合跨浏览器继续编辑，也意味着文件可能较大。

## 技术说明

React + TypeScript + Vite。编辑器以可序列化的 SVG 场景实现，作品坐标与视口变换分离；导出使用独立、无编辑控件的 SVG 场景再以 2× 像素比栅格化。画布文档版本目前为 `1`。

## 已知边界

- 浏览器原生不稳定支持 HEIC，界面会提示改用 JPG/PNG/WebP。
- 照片以 data URL 存在本地数据库；非常多超大照片可能触及浏览器配额，导入时会把最长边超过 2600px 的图片压缩。
- 首版相框裁切用方向与缩放按钮操作，未提供框内照片直接拖拽。
- 纯前端本地版本不含账号或云同步；项目文件是跨设备继续编辑的方式。
