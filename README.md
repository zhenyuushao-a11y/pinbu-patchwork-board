# 拼布

无需注册、打开就能动手的中文布艺线索板。可把布片、花瓣、针脚、相框、自己的照片和文字自由摆放，完成旅行手账、纪念板或贺卡，并导出高清 PNG 与可继续编辑的项目文件。

## 本地运行

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址。生产构建：

```bash
pnpm build
pnpm preview
```

静态文件输出到 `dist/`，可部署到任意静态托管服务。

## 发给组员试用

- **继续编辑同一件作品**：在“导出”中选择“发给组员继续编辑”，把 `.pinbu.json` 发给组员；文件会带上布局、照片和这件作品实际使用到的自定义布料。
- **同一局域网临时试用**：运行 `pnpm dev:lan`（或先构建后运行 `pnpm preview:lan`），把终端显示的局域网地址发给连接同一 Wi-Fi 的组员。每个人的作品仍只保存在自己的浏览器里。
- **跨网络网址试用**：需要部署到可访问的网址。当前 48 种新版素材按私人学习用途管理，因此在公开发布前应先由项目成员明确确认素材范围与访问方式。

## 已实现

- 首次打开先选“跟着做布花 / 图片转纸样 / 空白画布”，不再把新用户直接丢进编辑器
- 创作进度按“纸样 → 放布 → 裁布与拼贴 → 针脚细节 → 完成”给出下一步，也可随时收起
- 图片可生成轮廓纸样、4/6/8 色色块纸样或半透明手动描图底稿，纸样可调深浅与显隐，不会出现在最终 PNG 中
- 纸样在编辑时始终位于布片上方，便于对齐拼贴；可一键隐藏、缩放、旋转与复位，且始终不进入导出图片
- 素材模型改为“基础布料 × 裁剪形状”：先点击或拖入整块布，再通过选中工具栏或桌面端右键裁成方块、三角、圆、条带、花瓣、叶片、拱形、波浪或手绘自由轮廓
- 裁剪预览可直接拖动布料选择纹样范围，也可缩放布纹；画布内还可贴着纸样自由描边裁剪，并实时显示红色轨迹核对重合程度
- 裁剪是非破坏性的：同一块布可重新裁剪、移动布纹或恢复整块布
- 用户可上传自己的布料，浏览器本地建议颜色与纹样，用户确认名称、颜色、纹样和材质后收入“我的布料”
- 筛选仅显示当前确实有结果的选项，并显示实时数量；同维度取并集、跨维度取交集
- 默认原创示例板、空白板与横/竖/方三种尺寸
- 452 件可拼布片：432 件由 48 种私人基础布纹加工，另有 20 件原创 SVG 布片
- “旧布花园 / 乡居格纹 / 暮色植物 / 靛蓝与薄绡”四个审美系列，可一键切换后继续叠加颜色、形状、材质与纹样筛选
- 布片、零件、相框、灵感系列四类素材；颜色、形状、材质、纹样多选组合与关键词搜索
- 点按或桌面拖放添加，物件移动、旋转、缩放、水平/垂直翻转、复制、删除、层级调整；选中后的缩放和旋转入口固定在工具条前部
- “全部图层”面板按视觉层级列出纸样、布片、文字、照片和缝线；点一层会选中并把视图定位到该物件
- 可直接用鼠标或触控画缝线；每段缝线是可移动、缩放、旋转的独立图层，画完仍可在平针、十字针、锁边针和链式针之间切换
- 选中任意布片可“自动缝边”，系统会读取方块、花瓣、叶片及自由裁剪等真实轮廓生成独立缝线；颜色、粗细、针距、透明度与离边距离均可调整
- 可拆开的预组合布花；拆开保持视觉位置并支持撤销恢复
- 双端可调的独立针脚线
- JPG/PNG/WebP 文件选择与拖放；照片独立放置或落入相框
- 相框内照片平移、缩放、换框保留裁切
- 中英文字、数字、换行、字号与颜色
- 视口平移、缩放、回到全景；键盘撤销/重做、删除和方向键微移
- IndexedDB 自动保存，多作品互不覆盖，刷新恢复
- 2× 高清 PNG 导出；`.pinbu.json` 项目包含布局、用户照片和作品已使用的自定义布料，可发给组员继续编辑
- 损坏图片、HEIC、无效项目和保存/导出失败的中文错误提示
- 可更换画布底色或上传 JPG/PNG/WebP 作为图片背景；支持铺满、完整显示、拉伸和深浅调整，背景固定在图层面板最底层并随项目保存、PNG 导出
- 响应式桌面与移动端素材抽屉及折叠筛选面板

## 本地数据与隐私

这是纯前端应用。用户照片、排版和裁切数据保存在当前浏览器 IndexedDB；照片不会上传。项目文件会把照片以 data URL 包含在 JSON 中，适合跨浏览器继续编辑，也意味着文件可能较大。

## 素材与来源

- [ASSETS.md](./ASSETS.md)：内置素材许可、目录字段和贡献步骤
- [SOURCES.md](./SOURCES.md)：工艺资料、视觉关系与使用边界
- `public/assets/catalog.json`：逐项机器可读清单
- `assets/private-source/manifest.json`：48 种私人基础布纹、加工文件与本地使用范围
- `assets/sources/source-manifest.json`：保留的 40 张 CC0 旧库纹理来源记录（新版界面不再默认使用）
- `public/assets/fabric-overview.webp`：432 件新透明加工布片的浅/深底总览
- `scripts/fetch-textures.mjs`：从两个官方 API 下载已选 CC0 原图
- `scripts/process-textures.py`：透明蒙版、抗锯齿毛边、缩略图和标签生成流程
- `scripts/build-private-fabric-pack.py`：私人基础布分离、边缘清理与九类轮廓批量生成流程
- `scripts/generate-assets.mjs`：原创 SVG 与正式目录合并流程

代码使用 MIT License；原创 SVG 素材使用 CC BY 4.0；Poly Haven 与 ambientCG 旧库基础纹理及其加工件为 CC0。新版 48 种基础布纹是根据用户提供的参考提炼气质后生成的私人学习素材，暂不纳入公开站点或公开素材许可。社交媒体截图仅作为视觉参考，未原样入库。

## 重新获取与加工素材

仓库已包含可直接运行网站所需的本地素材，日常安装不需要联网重新下载。需要复现新版私人素材流水线时：

```bash
python3 scripts/build-private-fabric-pack.py
node scripts/generate-assets.mjs
python3 scripts/build-overview.py
pnpm test
```

图像加工步骤需要 Python 3 与 Pillow。旧 CC0 素材流水线仍可通过 `pnpm fetch:textures` 和 `pnpm process:textures` 复现。

## 技术说明

React + TypeScript + Vite。编辑器以可序列化的 SVG 场景实现，作品坐标与视口变换分离；导出使用独立、无编辑控件的 SVG 场景再以 2× 像素比栅格化。画布文档版本目前为 `1`。

## 已知边界

- 浏览器原生不稳定支持 HEIC，界面会提示改用 JPG/PNG/WebP。
- 照片以 data URL 存在本地数据库；非常多超大照片可能触及浏览器配额，导入时会把最长边超过 2600px 的图片压缩。
- 首版相框裁切用方向与缩放按钮操作，未提供框内照片直接拖拽。
- 纯前端本地版本不含账号或云同步；项目文件是跨设备继续编辑的方式。
- 当前新版素材包按私人本地学习用途管理，尚未部署到公开网址；若未来重新公开，应再次审查素材范围与许可说明。
